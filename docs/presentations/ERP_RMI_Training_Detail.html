Menu View Filter

Menu ERP bisa difilter sesuai kebutuhan:

  • Sesuai Dept — Tampilkan hanya modul yang relevan dengan dept user (default)

CRM — O2C Ringkas

1 CRM: Buat DO → Submit

2 WQS: Pick DO → Foto stok → READY SCM

3 SCM: Atur pengiriman → DELIVERED + POD

4 ACT: Tukar faktur → Set WAIT PAYMENT

5 FIN: Upload bukti bayar → POSTING → paid

Control Tower untuk tracking. Tax Invoice untuk faktur pajak.

Stage 1: CRM — Buat DO

Dept: CRM

Halaman: sales_do.php (Menu CRM → Sales → Open CRM Stage)

  1. Pilih Customer (harus ada di master_customers)
  2. Pilih Office (BGR, BKS, dll — sesuai cabang yang jual)
  3. Tambah item: Produk, Qty (cek pricelist jika harga otomatis)
  4. Simpan → Status DRAFT
  5. Klik Submit → Status berubah crm_to_wqs / sent_wqs → DO masuk ke WQS

DO Code otomatis: RMI-{OFFICE}-YYMMDD-XXX (contoh: RMI-BGR-260306-001)

Stage 2: WQS — Pick & Siap Kirim

Dept: WQS

Halaman: wqs_picking.php (Menu Stock → Picking) atau stock/wqs_do_tasks.php

  1. Lihat DO yang status sent_wqs / crm_to_wqs
  2. Klik Start → status wqs_processing
  3. Upload foto kartu stok (wajib — bukti fisik)
  4. Set READY SCM → status ready_scm / wqs_done
  5. Stock kantor pengirim berkurang

Tanpa foto stok, jangan set READY SCM. Control Tower untuk cek DO stuck.

Stage 3: SCM — Pengiriman & POD

Dept: SCM

Halaman: scm_do_tasks.php (Menu CRM → SCM Stage Tasks)

  1. Lihat DO yang ready_scm / wqs_done
  2. Atur pengiriman (carrier, tracking)
  3. Set status on_delivery saat barang dikirim
  4. Saat barang sampai: Upload POD (Proof of Delivery)
  5. Set DELIVERED → status delivered / scm_done

POD wajib — bukti barang diterima customer. Tanpa POD jangan set DELIVERED.

Stage 4 & 5: ACT → FIN

Dept: ACT, FIN

ACT (act_do_tasks.php): Tukar faktur dengan customer → Upload dokumen tukar faktur → Set WAIT PAYMENT → status wait_payment

FIN (fin_do_tasks.php): Upload bukti pembayaran → Isi tanggal bayar → Klik POSTING → status paid → Selesai

Tax Invoice (tax_invoices.php) untuk input faktur pajak. Setelah paid, DO closed.

WQS — Incoming (Terima Barang)

Halaman: wqs_incoming.php

  1. Pilih PO Code (untuk barang dari pembelian) atau DO Code (untuk transfer antar kantor)
  2. Input qty received per item
  3. Upload foto kartu stok / bukti terima
  4. Simpan → Stock kantor penerima bertambah

Pembelian antar kantor: BKS harus pick DO dulu, baru BGR input Incoming. Jika terbalik → stock dobel!

Pembelian Antar Kantor — Step-by-Step

BGR beli dari BKS. via PO + Sales DO (bukan Transfer).

LangkahPihakAksi
1BGR (penerima)Buat PR → PO ke manufacture "Kantor BKS"
2BKS (supplier)Buat Sales DO (customer=BGR-INT, office=BKS)
3BKSPick DO → foto stok → READY SCM → stock BKS berkurang
4BGRTerima via WQS Incoming (PO code) → stock BGR bertambah

Urutan wajib: BKS pick dulu, baru BGR Incoming. Customer BGR-INT, BKS-INT, dll di master_customers.

DO Code — Format & Contoh

Format: RMI-{OFFICE}-YYMMDD-XXX

Contoh: RMI-BGR-260306-001

  • RMI — Prefix perusahaan
  • BGR — Office (Bogor)
  • 260306 — Tanggal (26 Maret 2006 atau 26-03-06)
  • 001 — Nomor urut per hari

DO Code otomatis saat simpan. Office menentukan DO dari cabang mana.
