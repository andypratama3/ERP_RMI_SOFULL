# Onboarding — User Baru, Office/Depo Baru

**Lokasi lengkap:** [docs/onboarding/ONBOARDING.md](onboarding/ONBOARDING.md)

---

Ringkasan:

- **User baru:** Master System Login → RBAC Center → assign permission
- **Office/depo baru:** Master Office → code 3 huruf (BGR, BDG, SLO, dll.)
- **FIN approval:** Hanya MgrFIN_BGR + SYS untuk approve/pay
- **RBAC management:** SYS only (SYSTEM.RBAC_MANAGE, SYSTEM.USER_MANAGE)
