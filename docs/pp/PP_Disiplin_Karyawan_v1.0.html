1. Tujuan

Menetapkan aturan dan kebijakan tindakan disipliner terhadap karyawan yang melanggar peraturan perusahaan, kode etik, atau standar kerja. Memastikan penanganan yang adil, terukur, dan terdokumentasi.

2. Definisi

  • Surat Peringatan 1 (SP 1): Peringatan tertulis pertama untuk pelanggaran ringan.
  • Surat Peringatan 2 (SP 2): Peringatan tertulis kedua untuk pelanggaran sedang atau pengulangan setelah SP 1.
  • Surat Peringatan 3 (SP 3): Peringatan tertulis ketiga untuk pelanggaran berat atau pengulangan setelah SP 2. Dapat diikuti pemutusan hubungan kerja.
  • Peringatan Lisan: Teguran verbal (bukan tertulis). Dapat mendahului SP 1 untuk pelanggaran sangat ringan.

3. Tingkat Pelanggaran & Sanksi Progresif

TingkatDeskripsiContoh PelanggaranSanksi Umum
Ringan Pelanggaran pertama, dampak terbatas Terlambat berulang, tidak mengaktifkan GPS delivery tanpa alasan valid, absen tanpa izin 1–2 hari, tidak memakai seragam/ID Peringatan lisan → SP 1
Sedang Pelanggaran berulang atau dampak signifikan Pengulangan setelah SP 1, ketidakpatuhan prosedur yang menyebabkan risiko, konflik dengan rekan kerja, penggunaan aset perusahaan tidak sesuai SP 2 (+ pembinaan wajib)
Berat Pelanggaran serius atau berulang setelah SP 2 Pengulangan setelah SP 2, pelanggaran kode etik (suap, gratifikasi), ketidakjujuran, pelanggaran keamanan data, tindakan yang merugikan perusahaan SP 3 → evaluasi PHK

4. Penganggaran (Siapa Berwenang Mengeluarkan SP)

Tingkat SPBerwenang MengeluarkanApproval
SP 1 Manager langsung (atasan langsung karyawan) Manager Dept / Head Dept (informasi)
SP 2 Manager Dept / Head Dept HR Manager (review) + Director terkait (approval)
SP 3 HR Manager + Director terkait COO / HR Director (approval final)

Catatan: Untuk karyawan level Manager, penganggaran disesuaikan satu level di atas (Director/COO).

5. Masa Berlaku SP

  • SP 1: Berlaku 6 bulan. Jika tidak ada pelanggaran berulang dalam periode tersebut, SP 1 dianggap selesai (tetap tercatat di file personalia).
  • SP 2: Berlaku 12 bulan. Syarat sama.
  • SP 3: Berlaku 12 bulan. Evaluasi lanjutan: perbaikan atau rekomendasi PHK.

6. Prosedur Umum

  1. Atasan mendokumentasikan temuan pelanggaran (bukti, saksi jika ada).
  2. Pembicaraan dengan karyawan (hak untuk didengar).
  3. Penentuan tingkat pelanggaran sesuai tabel di atas.
  4. Pengisian Form Disciplinary Action (HRL-HR-FORM-003).
  5. Penandatanganan oleh atasan berwenang dan karyawan (atau dicatat penolakan tanda tangan).
  6. Salinan ke HRL untuk arsip personalia.

7. Dokumen Terkait
