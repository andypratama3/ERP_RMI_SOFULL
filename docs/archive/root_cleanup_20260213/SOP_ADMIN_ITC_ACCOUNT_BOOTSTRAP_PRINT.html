SOP Singkat Admin/ITC - Bootstrap Akun & Mapping Employee

Dokumen operasional internal
Tujuan: onboarding akun cepat dan terkontrol dari master_departements.

Prasyarat

  • Login sebagai ADMIN atau SUPERADMIN (untuk seed akun otomatis).
  • Data master_departements sudah tersedia dan status active.
  • Data master_employees tersedia untuk mapping holder.

Langkah 1 - Seed akun otomatis

  1. Buka master/master_system_login.php.
  2. Di panel kiri pilih section Seed Akun dari Master Departements (Fase 3).
  3. Isi default_password (atau default 1234) lalu klik Seed Akun Otomatis.
Hasil akun: Mgr{DEPT}_{OFFICE} dan Staff{DEPT}_{OFFICE}.
Jika username sudah ada, sistem otomatis skip (idempotent).

Langkah 2 - Mapping holder employee

  1. Di halaman yang sama, cari user lalu klik Edit.
  2. Masuk ke section Holder Employee (Akun Jabatan).
  3. Isi Employee Code, opsional Catatan, lalu klik Set Holder.
  4. Untuk melepas holder, klik Clear Holder.
Alternatif massal: gunakan Import Holder CSV
Header wajib: username,holder_employee_code
Header opsional: note

Langkah 3 - Verifikasi & kontrol

  1. Buka master/account_readiness.php untuk cek akun active yang belum lengkap assignment.
  2. Buka tools/review_kit_workspace.php?mode=single untuk monitoring terpadu.
  3. Cek jejak audit pada:
    • uploads/audit_logs/audit_master_system_login.log
    • Panel Unified Module Audit Log di tools/review_kit_workspace.php

Catatan Kontrol Akses

  • Seed akun otomatis hanya untuk ADMIN/SUPERADMIN.
  • ITC Manager dibatasi untuk akun yang diperbolehkan kebijakan RBAC.
  • Seluruh aksi sensitif diproses via POST + verifikasi CSRF.
