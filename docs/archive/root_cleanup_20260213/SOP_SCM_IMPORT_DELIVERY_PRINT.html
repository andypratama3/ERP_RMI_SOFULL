SOP SCM / Import Delivery

Dokumen SOP modul - versi 2026-02-11

Tujuan: memastikan proses operasional modul berjalan standar, aman, dan terukur.

Ruang Lingkup

  • purchases/*
  • dashboards/procurement/*

Prasyarat

  • User sudah login dan memiliki role sesuai kewenangan modul.
  • Data master terkait sudah valid (office, department, user, product, vendor, customer).
  • Semua mutasi dilakukan lewat mekanisme resmi sistem.

Langkah Operasional

  1. Verifikasi kelengkapan dokumen import dan status shipment.
  2. Pastikan milestone proses (booking, customs, delivery) ter-update.
  3. Koordinasi dengan PQP, WQS, dan FIN untuk kesiapan penerimaan dan pembayaran.
  4. Eskalasi shipment risk atau overdue sebelum berdampak ke SLA pelanggan.
  5. Arsipkan dokumen final untuk audit dan compliance.

Kontrol dan Kepatuhan

  • Dokumen import harus valid sebelum status lanjut.
  • Perubahan jadwal kritikal harus dikomunikasikan resmi.
  • Audit trail wajib ada untuk perubahan milestone.

Bukti Operasional

  • Simpan bukti transaksi, approval, dan exception penting.
  • Gunakan dashboard/KPI untuk monitoring performa harian dan bulanan.
  • Gunakan audit log untuk investigasi jika terjadi mismatch.

Eskalasi

  • Jika ada anomali data, hold proses lanjutan dan eskalasi ke PIC modul + ITC.
  • Jika ada risiko keamanan/akses, eskalasi ke Security/ITC dan lakukan containment.
