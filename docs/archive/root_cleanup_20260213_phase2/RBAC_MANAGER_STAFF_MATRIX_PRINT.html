RBAC Manager vs Staff Matrix

Sumber: baseline policy aktif di _shared/rbac.php (`$extraByDeptRole`) + base permission umum.

Aturan Umum

  • ADMIN / SUPERADMIN / OWNER: allow all (kecuali guard khusus modul tertentu).
  • Semua dept + role (MANAGER dan STAFF) dapat base permission: ABSENSI.VIEW, ABSENSI.CHECKIN, ABSENSI.REQUEST.
  • Matrix di bawah menunjukkan tambahan permission per departemen.
